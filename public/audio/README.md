# Royalty-Free Music Tracks for NavGurukul Birthday Board

Place your audio files in this directory (`public/audio/`).

The board uses **Howler.js** to stream these audio files with smooth fading. If any file is missing, it **automatically falls back to synthesized Tone.js music in the browser**, so nothing breaks!

## Format & Quality Guidelines

- **Format**: `.mp3` (128 kbps to 192 kbps CBR/VBR is ideal for fast web loading).
- **Looping**: For background tracks (`party.mp3`, `mehfil.mp3`, `pinboard.mp3`, `starlight.mp3`, `pop.mp3`), prefer tracks with seamless loop points or smooth ambient transitions.
- **Duration**: 1–2 minutes per loop is plenty.
- **License**: Royalty-free / Creative Commons (CC0 or CC-BY), such as from [Pixabay Music](https://pixabay.com/music/) or [Free Music Archive](https://freemusicarchive.org/).
